📋 How to Get Client ID & Secret

Select a service, register, create an OAuth App, copy the Client ID & Secret.

  1. Spotify: developer.spotify.com
  2. Google: console.cloud.google.com
  3. GitHub: github.com/settings/developers
  4. Notion: notion.so/my-integrations
  5. Slack: api.slack.com/apps

Redirect URI: http://localhost:3000/api/oauth/spotify/callback
