🧩 5 Mode Onyx

Onyx punya 5 mode. Tiap mode punya cara berpikir dan kemampuan yang beda. Pilih mode sesuai kebutuhan lo.

⚡OperatorDEFAULT

Cocok buat: Tugas sehari-hari, tanya jawab cepat, cari info.

Cara kerja: Onyx langsung eksekusi. Kalau butuh data, dia cari. Kalau udah cukup, dia jawab.

  • Cari internet (DuckDuckGo)
  • Cari kode (GitHub)
  • Ambil isi halaman (fetch)
  • Generate gambar

🧠Reasoner

Cocok buat: Pertanyaan rumit, analisis mendalam, debat, filsafat.

Cara kerja: Onyx mikir 6 langkah:

  1. Uraikan pertanyaan
  2. Bikin hipotesis
  3. Uji bukti
  4. Cek kontradiksi
  5. Sintesis
  6. Kritik diri

  • Multi-step thinking
  • Self-critique
  • Logic chain
  • Cari bukti dulu sebelum jawab

💻Coder

Cocok buat: Bikin program, debug, belajar coding.

Cara kerja: Onyx tulis kode, jalanin, baca error, benerin, ulang. Kayak programmer beneran.

  • Tulis kode lengkap
  • Jalanin kode (Python/Node.js)
  • Auto-debug
  • Cari referensi di GitHub

🔍Researcher

Cocok buat: Riset serius, OSINT, cek fakta, investigasi.

Cara kerja: Onyx cari dari banyak sumber, cross-check, verifikasi, baru lapor. Gak asal percaya.

  • Cari multi-sumber
  • Cross-check
  • Verifikasi
  • Laporan + sumber

🎨Creator

Cocok buat: Bikin konten, gambar, cerita, ide.

Cara kerja: Onyx kasih 2-3 ide, pilih yang terbaik, generate, revisi kalau perlu.

  • Generate gambar (Pollinations)
  • Bikin cerita
  • Kasih ide kreatif
  • Revisi sesuai request
