📝 Format Laporan

Biar cepet ditangani, kirim laporan dengan format ini:

  1. Mode: (Operator / Reasoner / Coder / Researcher / Creator)
  2. Versi Onyx: (liat di Setelan)
  3. Device: (HP / Laptop / PC — sebutin OS-nya)
  4. Error: (tulis pesan error-nya persis)
  5. Langkah reproduksi: (gimana caranya sampe error)
  6. Screenshot: (kalau ada)

⏱️ Waktu Respon

  • Email: 1-3 hari kerja
  • Telegram: 1-24 jam (kalau online)

🚨 Error yang Sering Terjadi

1. "Semua model gagal"

  • Cek: llama-server jalan?
  • Cek: .env ada API key Groq/Cerebras?
  • Solusi: restart server

2. "Gagal generate gambar"

  • Pollinations kadang lambat/down.
  • Coba lagi 1-2 menit.
  • Kalau masih gagal, lapor.

3. Chat gak kesimpen

  • Cek: folder data/chats/ ada?
  • Cek: server punya izin tulis?
  • Solusi: restart server

4. PWA gak bisa di-install

  • Chrome HP kadang gak fire beforeinstallprompt.
  • Solusi: menu Chrome → "Add to Home screen".
