## ⚡ What Onyx Can Do

- 💬 **Multi-language chat** — Casual or serious conversations
- 💻 **Coding & debug** — Write, run, fix code
- 🔍 **Research & OSINT** — Multi-source search, cross-check
- 🎨 **Image generation** — Create visuals from text
- 📊 **Data analysis** — Process CSV, Excel, databases
- 🐍 **Run Python** — Execute code directly
- 🔌 **Integrations** — Spotify, Google, GitHub, Notion, Slack

## 🛠️ Tech Stack

- **Backend:** Node.js + Express
- **Frontend:** HTML + CSS + JavaScript (PWA)
- **AI:** Multi-model (Groq, Cerebras, OpenRouter, Gemini)
- **Tools:** Web Search, Files, Python, Image
- **Database:** SQLite (sql.js)
- **Tunnel:** Ngrok + Cloudflare
- **Hosting:** Termux
